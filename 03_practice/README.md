# Part 3 – Practice Exercises

This folder contains small practice exercises for students to attempt after
the classroom demonstration.

- [`classification_practice.py`](classification_practice.py) – Exercises on
  Decision Tree, k-NN, and Naive Bayes.
- [`clustering_practice.py`](clustering_practice.py) – Exercises on k-Means
  and Hierarchical Clustering.

## How to Use These Files

1. Open the file and read each exercise description at the top.
2. Try writing the code yourself in the marked space below each exercise.
3. Run the file to check your output.
4. Only after attempting it yourself, scroll to the bottom of the file to
   compare your solution with the provided (commented-out) solution.

## Exercises Included

**Classification Practice:**
1. Build a Decision Tree to predict Pass/Fail.
2. Use k-NN to classify a simple dataset.
3. Use Naive Bayes to classify simple messages.

**Clustering Practice:**
1. Use k-Means to find 2 groups.
2. Change K from 2 to 3 and observe the result.
3. Use hierarchical clustering and display a dendrogram.
